circuit-composer

Milestone 1 done

Board design as composition: chips ingested once into verified packages, boards built by combining them. Sits between easy_pcb (schematic) and ultraroute (routing).

Where it stands

Intent schema v0 exists as Rust types with a generated JSON Schema, a validator, and a ccomp CLI that prints JSON. easy2350, easy_pcb's worked RP2350A board, is annotated by hand: its nets, 14 blocks, a domain tree, two part-anchored regions, and three protection paths. It passes the validator. Nothing places, generates or routes yet. That starts with milestone 2.

Working

  • Intent types: nets, blocks, ports, domains, regions, protection paths
  • JSON Schema generated; a test fails if the committed copy is stale
  • Validator: required fields per class, provenance on every hard constraint, pairs, pads
  • KiCad netlist reader (runs kicad-cli on a schematic)
  • Import from easy_pcb design/nets.csv
  • easy2350 annotated and passing; 17 tests

Next up
